# 心易 AI 命理决策助手 · 作品集文档索引

本文档集用于面试与作品集展示，目标是把 `AI-mingli-MVP` 从一个可运行 Demo 梳理成一个完整的 AI 产品验证案例。

项目定位：心易不是传统“算命工具”，而是把紫微斗数、八宅风水、六爻、合参等传统术数拆解为可计算的结构化信息，再用大模型完成白话解释、追问承接、风险拦截与决策陪伴。

## 面试讲述主线

这套材料建议按以下顺序讲：

1. 先讲为什么做：传统命理有稳定需求，但存在黑箱、吓人、难懂、无法追问的问题。
2. 再讲产品判断：把“预测命运”改成“陪用户想清楚”，以可解释、可追问、安全边界作为核心差异。
3. 再讲技术拆法：纯计算排盘负责事实层，RAG 负责知识层，大模型负责表达与对话层。
4. 再讲验证闭环：用评测集验证模型是否准确、白话、安全、可承接上下文。
5. 最后讲复盘：Bad case 如何暴露问题，如何通过 prompt、RAG、规则、UI 和产品边界修复。
