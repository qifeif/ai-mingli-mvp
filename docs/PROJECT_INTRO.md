# 心易 AI 命理决策助手 · 项目介绍

心易是一个把传统术数重新组织为 AI 决策陪伴工具的 MVP。它不把命理包装成确定预测，而是把紫微斗数、八宅方位、六爻与双人合参拆成可计算、可解释、可追问的结构化信息，再由大模型转译成白话建议。

项目核心判断是：用户真正需要的不是一句“准不准”的结论，而是在不确定时获得一个能帮助自己想清楚的框架。因此心易坚持“给视角，不替用户做决定”，并把危机风险拦截、安全表达与上下文承接放在产品流程前面。

## 在线体验路径

本地运行后访问：

```bash
npm install
npm run web
```

默认地址：

- 落地页：`http://localhost:3000/`
- 天命紫微：`http://localhost:3000/app`
- 地运八宅：`http://localhost:3000/diyun`
- 人间道六爻：`http://localhost:3000/renjiandao`
- 双人合参：`http://localhost:3000/hehun`
- 多轮对话：`http://localhost:3000/chat`

排盘、起卦、本命卦等基础能力为纯计算逻辑，不依赖 API Key；AI 解读、视觉户型点评与对话能力需要在 `.env` 中配置模型。

## 产品模块

| 模块 | 用户问题 | 技术拆法 | 输出形式 |
| --- | --- | --- | --- |
| 天命 | 我当前的长期走势与性格结构是什么？ | 真太阳时校正、紫微斗数排盘、三方四正结构化 | 命盘骨架、白话解读、流式深化 |
| 地运 | 我的居住环境怎样更适合当前诉求？ | 八宅东西四命、方位吉凶、可选户型图视觉分析 | 方位罗盘、身份诉求建议、逐间点评 |
| 人间道 | 当前这个问题的时机和取舍是什么？ | 三铜钱模拟、六爻本卦/动爻/变卦 | 卦象结构、象意解读、下一步建议 |
| 合参 | 两个人在恋爱、婚姻或合作中如何互补？ | 双人八字对照、十神互动、五行互补 | 关系结构、风险提醒、沟通建议 |
| 对话 | 我想基于刚才的结果继续追问。 | 跨页 handoff、priorReading 注入、流式多轮 | 连续问答、上下文续接 |

## 技术架构

项目采用轻量 Node.js HTTP 服务，不依赖前端框架即可运行完整体验。

- `server.js`：页面路由、静态资源、全部 API 聚合。
- `src/ziwei.js`：紫微斗数排盘、三方四正与流式解读。
- `src/bazhai.js`、`src/fengshui.js`：八宅方位与户型图点评。
- `src/liuyao.js`、`src/renjiandao.js`：六爻起卦与象意解读。
- `src/chat.js`、`src/stream.js`：多轮对话与通用流式 LLM 层。
- `src/pipeline.js`：危机检测、场景分类与安全边界。
- `public/`：新中式多页面前端体验。
- `tests/`：排盘、六爻、合参、RAG 与模型调用相关回归测试。

## 安全与体验原则

1. 不下定论：只给倾向、结构和可行动建议。
2. 危机前置：自伤、绝望、极端风险等内容优先进入支持性话术。
3. 术语白话化：命理术语必须翻译成生活语言。
4. 上下文不断：从排盘页进入对话页时保留刚才的解读。
5. 纯计算托底：没有模型 Key 时仍可完成基础排盘与结构化展示。

## 项目价值

这个 MVP 的重点不是复刻传统命理软件，而是验证一种更现代的 AI 产品形态：把高门槛、强文化语境、强解释需求的知识体系拆成“规则计算 + 知识检索 + 大模型表达 + 安全边界 + 多轮承接”的产品闭环。

它适合作为 AI 应用产品、Prompt/RAG 工程、传统文化数字化、用户体验改造与 MVP 验证案例展示。
