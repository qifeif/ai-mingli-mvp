## 这一版改了什么(相对「中式美学初版」)

### 1. 三个工具页:单列 → 双栏「工作台」+ 自适应
天命 / 地运 / 人间道从「居中单列 + 一个表单卡」重做为 **双栏 studio**:
- **编辑式 hero**:朱砂 kicker(含书法点睛词 观象入元 / 顺势调场 / 观象悟辞)+ 大号书法标题 + 一句「三才」定位 lede。
- **左主列**:表单卡(加卡头「命盘信息 / 居所信息 / 所问之事」+ 副标)。
- **右侧栏**(sticky):三张内容卡 —— ①「这一道是什么」介绍 ②编号「怎么用」三步 ③**三道互参**交叉导航卡(带图标,点击直达另外两道)。
- **结果整宽**展示;天命命盘双列网格,地运罗盘+详解并排。
- **响应式**:≤900px 单列堆叠,**表单优先**(操作可达),下接介绍/步骤/互参;≤560px 字号/间距收敛。
- 新增内容均补 **EN i18n**;补回人间道导航缺失的「人间道」自链接。

### 2. Logo 贯彻四页
四页 nav 左上统一为落地页那套「朱砂『易』印(`.seal-mini`)+ 心易(`.lt`)」锁定标(原工具页是渐变文字)。

### 3. 天命「紫微化」(定位/视觉层,后端未动)
- badge:`天命 · 子平八字 · 真太阳时` → **`天命 · 紫薇八字 · 真太阳时`**;侧栏介绍同步改紫微/三方四正口径。
- **去塔罗与西方占卜**,主打传统(全站零残留)。
- **功能键仿命理排盘 App**(参考 文墨天机 男/女 切换):性别、解读风格改为 **分段切换(`.seg`)**,墨色风。
- **结果:静态 Mock 紫微斗数十二宫命盘 + 三方四正解读**(`renderZiwei` / `sfszHtml`,纯前端写死数据,全程标注「示例 DEMO · 静态盘」):
  - 4×4 宫格 + 中央信息盘(命主/身主/火六局/真太阳时随表单动态回填)
  - 每宫:主星+亮度(旺庙平陷)+四化色标(禄绿/权金/科黛/忌赭)+副星+宫名(朱砂)+大限+干支
  - **命宫朱砂框**、**三方四正(命·迁·财·官)高亮**、身宫标记、图例
  - 下接三方四正解读面板(chips + 你的问题 + 演示解读三段,中英双文案)
  - AI 文字解读仍走真实 `/api/consult`(配 Key 生效,无 Key 降级提示)

### 4. /preview 增「页面一览」
预览页加 `#pages` 区块:iframe 实时嵌入四页,**页面 tab 切换 + 桌面/手机 390 视口切换 + 「全部」2×2 缩略图网格**(每张可点开)。
