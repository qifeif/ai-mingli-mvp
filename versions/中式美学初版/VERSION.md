# 心易 · 中式美学初版

> 定稿日期:2026-06-29　·　第一版统一视觉语言(新中式 / 山水留白)

这是「心易」全站第一版正式中式美学设计,首页与三个工具页统一在同一套设计令牌下。本目录是该版本的**快照备份**,用于日后回滚或对照。

## 快照内容(public/)
- `landing.html` —— 首页(山水 hero + 三道合一 + 为什么心易 + 易理为用 + 定价 + FAQ + 气韵 band)
- `index.html` —— 天命(子平八字)
- `fengshui.html` —— 地运(八宅方位)
- `renjiandao.html` —— 人间道(周易六爻)
- `preview.html` —— 风格预览页(/preview)
- `theme.css` —— 三个工具页共用的设计令牌
- `ink.js` —— 鼠标墨迹拖尾

## 首页 hero 文案(定版)
- 题签:EASTERN YI · MODERN DECISION　东方易理 · 现代决策
- 主标:心易(书法)+ 朱砂「心易之印」落款

- 副文(长文案版):承周易之体,演 AI 之用。把「算命」重做成陪你想清楚的决策工具——人生影响,天命占 1/3,地运占 1/3,人事占 1/3。
- 三才行:天命 / 地运 / 人间道 —— **每个字可点击直达对应工具**(/app、/diyun、/renjiandao)

## 关键决策
- 首页自包含内联样式(与 theme.css 同色值),与 /preview 渲染一致;三工具页用 theme.css。
- hero 取消独立模式按钮组,改由三才行文字本身承担直达入口(更留白)。
- 中英双语:导航 + hero + footer 走 i18n(EN/中 切换);正文区中文。
- 保留定价(微光/烛照¥39/洞见¥99)+ FAQ + 鼠标墨迹拖尾。
