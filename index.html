把传统命理重做成陪你想清楚的 AI 决策助手：给视角，不下定论；给结构，不替用户做决定。

三道合一

天命看结构，地运看环境，人间道看时机；再用合参与对话把结果承接成可继续追问的产品体验。

TIAN MING 天命 · 紫微

真太阳时校正、十二宫命盘、三方四正与流式 AI 深化，先出命盘骨架，再逐步生成白话解读。

DI YUN 地运 · 八宅

按东西四命推导方位建议，结合诉求与户型图，为居住环境给出更易执行的调整方向。

REN JIAN DAO 人间道 · 六爻

模拟三铜钱摇卦，生成本卦、动爻与变卦，用象意解释当下问题的节奏与取舍。

技术闭环

纯计算负责事实层，RAG 和知识库负责方法层，大模型负责表达、追问和安全承接。

输入出生信息、诉求、户型图或当前问题。
计算排盘、起卦、本命卦与结构化字段。
检索从本地知识库召回方法论与案例。
生成按安全边界输出白话解读和建议。
承接跨页保留上下文，进入多轮追问。

本地运行

基础排盘能力无需模型 Key；AI 解读、视觉点评和多轮对话需要配置 `.env`。

npm install
npm test
npm run web

# open http://localhost:3000
