# 婚恋合参里的十神组合详解

婚恋合参最常用的切入点,是看两人互为对方的什么十神,再看这两个角色放在亲密关系里会怎么互动。以下口径都只谈相处倾向,不谈"配不配"。

# 财印互看:照顾与被照顾

一方视另一方为财星、对方回看是印星,常见的体感是"一个想经营、一个被滋养"。顺的时候是彼此需要;拧的时候,经营方觉得自己一直在付出,被滋养方觉得被安排。建议的讲法:把"我为你做了什么"换成"你需要我做什么",付出先问需求。

# 官杀互看:敬重与压力并存

对方是我的正官,相处里自带分寸感和秩序感,容易"敬着处";对方是我的七杀,则推动力与压迫感并存,吵起来火药味重。建议的讲法:官杀式的关系要给"喘气的空间",定期有一段谁也不管谁的时间,张力才不会积成怨气。

# 食伤互看:表达与被激发

对方是我的食神,相处松弛、有滋养,容易一起把日子过出滋味;对方是我的伤官,则被激发的同时也容易互相抬杠、挑对方的理。建议的讲法:伤官式的互动把"辩赢"改成"说完",各自把话说完整,不接话茬三分钟。

# 比劫互看:同频与较劲

互为比肩劫财,像跟自己谈恋爱,懂彼此的骄傲与逞强,但资源、面子、主导权上容易暗暗较劲。建议的讲法:提前分好"谁的地盘谁做主",在对方的领地里只提问、不下令。

# 统一红线

任何十神组合都禁止说成"天作之合"或"天生相克"。组合只是起点,相处质量由两个人的沟通方式决定;每个摩擦点都要配一条可执行的"怎么办"。
