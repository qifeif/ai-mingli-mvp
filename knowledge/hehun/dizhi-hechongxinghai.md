# 地支关系的现代白话:合冲刑害各说什么

两盘地支两两对照,是合参的第二层。六合(子丑、寅亥、卯戌、辰酉、巳申、午未)讲"暗中相吸",两股能量天然亲近、好商量。三合(申子辰水、寅午戌火、巳酉丑金、亥卯未木,两支同局为半合)讲"同气相求",配合起来顺手省力。六冲(子午、丑未、寅申、卯酉、辰戌、巳亥)讲"节奏与立场对撞",常见的体感是一个要快、一个要稳,一个要变、一个要守。

# 相刑与相害的白话

相刑(寅巳申、丑戌未、子卯,辰午酉亥自刑)说的是"说不清的别扭":不是大是大非,而是相处里反复出现的小拧巴,越沉默越拧,越坦白越松。相害(子未、丑午、寅巳、卯辰、申亥、酉戌)说的是"细节处互相妨碍":大事未必,小事最磨,家务、花钱、时间安排这类日常最容易踩到。

# 哪些位置最要紧

日支在传统里对应婚姻宫、也是"自我之位",两人日支之间的合冲刑害对朝夕相处的体感影响最直接;年支对应家庭背景与长辈缘,月支对应做事习惯,时支对应晚年与私密面。合参先看日支对日支,再看其余显著组合,零散的次要组合不必逐一放大。

# 冲不是散,合不是成

必须澄清:六冲不等于"必分",它只提示分歧容易出现在节奏与立场上,预案是"先对齐节奏再谈对错";六合也不等于"必成",太合的组合可能互相迁就、把分歧藏到最后。合冲刑害是摩擦与吸引的"地形图",路怎么走始终在两个人手里。
