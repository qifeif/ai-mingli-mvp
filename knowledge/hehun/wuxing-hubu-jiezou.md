# 五行互补:一方的短板是另一方的长项

把两人的五行分布放在一起看:一方某个五行偏弱甚至全缺,而对方这个五行偏旺,就记一处互补。互补处多,说明两人的能量结构错位咬合,像齿轮——你缺的我有,我缺的你补;互补处少,说明两人是"同款节奏"的组合,共鸣多,但短板也容易一起缺位。

# 五行对应的性格节奏

木旺的人主生发:爱开头、爱计划、往前冲。火旺的人主表达:热情、外放、节奏快,容易点燃气氛也容易烧过头。土旺的人主承载:稳、能扛、慢热,是关系里的压舱石。金旺的人主决断:讲规则、能收尾、砍得下手。水旺的人主流通:灵活、善感、想得深,润物细无声。一方缺什么,往往就是相处里"总也做不来"的那部分,对方旺的正好补位。

# 互补怎么用成默契

互补度高的两人,建议把"我不擅长的"放心交给对方:火弱木弱的一方别硬逼自己冲锋,让对方开头;金弱土弱的一方别硬撑着收尾,让对方守盘。关键是交出去时说声谢谢,而不是各自较劲证明"我也行"。

# 同款节奏怎么办

互补度低不是坏事,同款组合共鸣深、话投机,但要警惕共同盲区:两人都缺金,就都容易开头热闹收尾拖;都缺土,就都容易飘。建议主动引入外部视角——朋友、清单、流程,替两个人把缺的那个角补上。互补度只是分工参考,不构成"合不合适"的结论。
