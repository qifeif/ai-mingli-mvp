# 十神互动总论:两个人互为对方盘里的什么

合参看两个人的关系,第一步是"十神互看":以甲的日主看乙的日干,得一个十神;再以乙的日主看甲的日干,又得一个十神。两个十神合起来,就是两人互动的第一层画像。要点是:十神说的是"对方在我生命里扮演的角色倾向",不是"对方是什么样的人",更不是关系成败的判决。

# 常见互看组合的白话口径

对方是我的正印或偏印:这个人容易让我有被托住、被理解的感觉,但也可能让我不知不觉依赖。对方是我的正官或七杀:这个人让我自觉收敛、讲规矩,正官偏"敬",七杀偏"压",两者都自带张力。对方是我的正财或偏财:我会想认真经营、想抓住这个人,正财踏实、偏财带新鲜感。对方是我的食神或伤官:这个人激发我的表达与才华,食神松弛滋养,伤官锋利、容易挑战规则。对方是我的比肩或劫财:像照镜子,平起平坐,懂彼此的骄傲,也容易较劲。

# 互看不对称是常态

甲看乙是正印,乙看甲可能是伤官——两人对同一段关系的体感天然不同,一方觉得安稳,另一方可能觉得被消耗。解读时必须两个方向都讲,并提醒:体感不同不代表谁对谁错,把各自的感受说出来对齐,比争论"到底谁付出多"有用得多。

# 表达红线

十神互看只描述互动倾向,禁止推断"命中注定在一起"或"注定不合"。任何组合都有顺的过法与拧的过法,落点永远是"这样的两股能量,怎么配合更舒服"。
