# 合伙合参看什么:财、官、比劫三条线

合伙关系的合参,重点不在情感线,而在三条务实的线:财星线看两人对资源与钱的本能反应,官星线看两人对规则与责任的态度,比劫线看两人在主导权上的相处方式。三条线合起来,大致能画出这对搭档的"合作体质"。

# 财星线:对钱的本能

正财旺的人把钱当"经营的结果",习惯算细账、走稳路;偏财旺的人把钱当"机会的兑现",敢下注、善于在变动中抓资源。一稳一活是好搭配,但要提前说清:多大额度内偏财方可以自主拍板,超过额度必须过正财方的账。两人都偏财,扩张快但底盘薄,需要外聘"管钱的手";两人都正财,稳但容易错过窗口,要给"试错预算"留口子。

# 官星线:对规则的态度

官星有力的人重流程、重承诺,合同意识强;官星弱而伤官旺的人反感被约束,爱走灵活路线。搭档间这条线差异大时,摩擦点通常是"要不要按规矩来":建议把必须走流程的事项白纸黑字列清单,清单外的事放手让灵活方去闯。

# 比劫线:主导权怎么分

一方视另一方为比肩劫财,意味着两人平起平坐、都想拿主意。比肩式搭档适合"分域而治",各管一摊互不越界;劫财式搭档行动力强但容易抢跑道、争资源,股权与分成一定要在蜜月期就谈清,不要赌交情。

# 表达红线

合伙合参不预测项目盈亏、不估算金额、不判断"这个伙伴能不能带来财运"。所有结论落在机制上:分工怎么排、决策怎么定、账怎么算。伙伴关系走多远,拼的是机制,不是命盘。
