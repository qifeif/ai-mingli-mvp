# 合伙分工:按能量结构排角色

两盘对照后排分工,基本思路是"谁的能量旺,谁主扛对应的事"。木火旺、食伤有力的一方,适合主外:开拓、谈判、对外表达、找机会;土金旺、官印有力的一方,适合主内:守盘、流程、风控、把交付兜住。水旺的一方常是好的"中间件",适合协调与信息流通。分工顺着盘走,省力;逆着盘硬扛,两人都累。

# 决策风格的常见差异

日主偏旺、七杀伤官有力的人,决策快、敢拍板、容错高;日主偏弱、印星重的人,决策前要安全感,倾向多查多问、慢慢定。快慢本身没有优劣,危险的是互相看不上:快的嫌慢的磨叽,慢的嫌快的莽撞。建议的机制:小事按域各自拍板不复议;大事走"提案—冷却—合议"三步,快方出提案,给慢方一个明确的冷却期限,到期必须给结论,谁也不许无限拖。

# 僵持怎么破

两人日主相克或互为比劫的组合,最容易在僵持上耗。提前约定破局规则:各自领域内本人有最终决定权;共同领域僵持时,可以约定听第三人的、听数据的、或者轮流让——规则本身是什么不重要,重要的是在没吵架的时候就把规则定好。

# 复盘机制

建议每月一次"只谈机制、不谈对错"的复盘会:哪个环节掉球了、边界要不要重划、额度要不要调整。合参给出的是两人协作的先天倾向,机制是后天的补丁;倾向不能改,补丁可以一直打。不要用命盘给合作下"能成/不能成"的断语。
