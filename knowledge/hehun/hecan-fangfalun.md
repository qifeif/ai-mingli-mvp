# 合参方法论:两盘互参怎么看、看到哪为止

合参(双人八字对比)的正确姿势是"两盘互参、分层递进":先各自立盘,看清每个人自己的底色,再做对照——单盘没看懂就急着对比,是最常见的方法错误。对照层通行的顺序是四步:第一步看日主天干的生克合(两股核心能量怎么互动),第二步十神互看(彼此在对方生命里的角色),第三步地支合冲刑害(摩擦与助力容易落在哪类事上,日支最要紧),第四步五行互补(能量结构是错位咬合还是同款节奏)。有大运信息的,可加看两人当前阶段的节奏是否同频。

# 权重与取舍

四层信息不等权:日主关系与十神互看定"底色",地支关系定"摩擦点",五行互补定"分工"。日支对照权重最高,因为日支即传统所说的婚姻宫、自我宫,朝夕相处的体感最直接;年支对照权重最低,更多是家庭背景与大环境的呼应。同一对地支既见合又见刑时,两说并陈,不取吓人的那头。显著的少数几条,比面面俱到的一大篇更有用。

# 不下定论是方法本身,不是客套

合参输出的是"互动倾向地图",不是判决书。方法层面必须守住三条边界:一,不回答"能不能结婚""该不该散伙"这类替人做决定的问题,只提供看问题的角度;二,任何摩擦项必须配"怎么办"的建议,只报忧不给路是不负责任的解读;三,盘面相同的两对人,因为沟通方式与经营投入不同,走出的关系完全不同——这正是合参只能"参"不能"断"的根本原因。

# 给解读者的自查清单

输出前自查:有没有把某一层结构放大成整体结论?有没有用"注定""必然"式措辞?摩擦项是否都配了可操作的建议?术语是否都翻译成了生活语言?最后是否把关系的主动权交回给了两个人?五问全过,才算合格的合参。
